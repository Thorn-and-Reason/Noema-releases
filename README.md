# Noema downloads

Noema is the Thorn & Reason app for qualitative analysis: import sources, code passages, organise cases and memos, compare evidence, and export reports. Saved projects and saved-study crash recovery are encrypted. Application source is maintained separately.

[Checksums](https://github.com/Thorn-and-Reason/Noema-releases/releases/download/v0.2.1-beta.1/SHA256SUMS.txt) · [Release notes](https://github.com/Thorn-and-Reason/Noema-releases/releases/tag/v0.2.1-beta.1) · [Update feed](https://github.com/Thorn-and-Reason/Noema-releases/releases/download/beta/latest.json)

Updater packages carry cryptographic signatures bound to their version. Mac beta packages are ad-hoc signed and unnotarised; Windows installers have no Authenticode signature and were cross-built. Native GUI, screen-reader, and physical hardware acceptance remain unverified. REFI-QDA is an exchange format, not a claim of lossless NVivo compatibility.
