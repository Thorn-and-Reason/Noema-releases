# Noema downloads

Noema is the Thorn & Reason app for qualitative analysis: import sources, code passages, organise cases and memos, compare evidence, and export reports. Saved projects and saved-study crash recovery are encrypted. Application source is maintained separately.

## Current beta: 0.2.1-beta.2

More readable coding metadata, clearer matrix actions, and a narrow coding panel that keeps the selected quotation and code controls together. Source selection, headings, and reading now have separate scroll areas so they do not overlap.

Mac beta packages are ad-hoc signed and unnotarised. Windows installers are cross-built without Authenticode. Frontend production builds and screenshot captures were checked during this UI update. Broader test suites, native GUI and installed-update behaviour, screen-reader speech, hardware operation, and optional-AI acceptance were not repeated. Screenshot review does not establish accessibility conformance.
